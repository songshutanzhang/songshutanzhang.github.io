# 数据许可与来源

本项目将代码与第三方数据分开授权。

## 代码

`src/`、`scripts/`、测试与构建配置采用根目录 [MIT License](LICENSE)。

## 目录数据

`data/works.js` 中的作品元信息、简介和题材标签，来自 [Bangumi 番组计划](https://bgm.tv) 的用户贡献条目，源站声明这些条目信息遵循 [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/deed.zh)。该快照是对入选条目的摘取与本地改编，包括：

- 只选取 327 部策展作品，而非完整数据库；
- 简介截断为约 220 字并清理排版；
- 将社区标签归并为本地题材体系；
- 人工补充或修正少量中文标题、题材、简介与搜索别名。

上述数据作为 Bangumi 数据的衍生集合，按 CC BY-SA 3.0 提供。再分发时请保留本说明、应用内署名，并链接到 Bangumi 的[版权声明](https://bgm.tv/about/copyright)及 CC BY-SA 3.0 协议。

## 封面与作品名称

- 本项目的构建产物**不包含**动画封面图片，只保存 Bangumi 提供的远端图片 URL，并在用户浏览时由浏览器请求。
- 封面图片、作品名称与相关角色形象的权利归各动画制作方、出版社、发行方或其他原权利人所有。使用这些图片或名称时，应遵守适用法律及各权利人的要求。
- 本项目仅用于非商业的动画目录索引、记录与介绍，不隶属于 Bangumi、AniList 或任何动画制作/发行公司，也未获得其背书。

## 提示词样例

`assets/prompt.md` 是随项目提供的分析提示词样例，作为本项目内容一并交付。界面允许用户修改其中 JSON 以外的文字；应用在本地组合用户记录 JSON，不调用任何第三方模型服务。

## 构建工具

项目开发依赖 Vite、TypeScript、Vitest、Playwright 与 tsx，均只用于本地构建和测试，遵循各自的许可证；最终单文件构建产物不包含这些工具的运行时。
