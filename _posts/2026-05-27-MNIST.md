# 项目背景  
&emsp;&emsp;28x28 像素的灰度图像，代表一个手写数字，像素坐标为 0-783 ，每个坐标对应一个灰度值 0-255.

&emsp;&emsp;提供两个 csv 文件，分别为 test.csv（测试集，不含标签）与 train.csv（训练集，包含标签）  
&emsp;&emsp;测试集有 28000 个数据点，训练集有 42000 个数据点。

# 问题分析 #

## 模板法 

&emsp;&emsp;我们的目标是从含有标签的数据中推断出 0-9 这 10 种数字对应的规律。

&emsp;&emsp;容易想到 `模板法` ，即构造 10张“平均图”，找到每类数字每个像素对应的平均灰度，与样例作差求平方和，偏差的最小值即为最有可能的数字。这个方法的优点是解释简单，比较逻辑轻松，只需要最基本的 Numpy 与 Pandas 库即可实现。

![](/assets/img/template.png)

&emsp;&emsp;完整代码如下：

```Python
import numpy as np
import pandas as pd

# 1. 读取并划分数据集

raw_data = pd.read_csv("train.csv")

# 验证集：前 2000 行
val_data = raw_data.iloc[:2000]
# 训练集：2000 行之后的所有数据
train_data = raw_data.iloc[2000:]

# 提取训练集的标签和像素
train_labels = train_data.iloc[:, 0].values
train_pixels = train_data.iloc[:, 1:].values

# 提取验证集的标签和像素
val_labels = val_data.iloc[:, 0].values
val_pixels = val_data.iloc[:, 1:].values

print(f"数据集划分完成：训练集 {len(train_pixels)} 行，验证集 {len(val_pixels)} 行。")

# 2. 训练阶段：构建均值模板

templates = np.zeros((10, 784)) #归零化

for digit in range(10):
    digit_mask = train_labels == digit #布尔判断筛选目标标签图像，返回掩码
    templates[digit] = np.mean(train_pixels[digit_mask], axis=0) #按行计算平均模板

print("均值模板构建完毕。")

# 3. 验证阶段：在验证集上测试并计算准确率

correct_predictions = 0

for i, val_sample in enumerate(val_pixels):
    # 计算当前验证样本与 10 个均值模板的平方和
    squared_diff = (templates - val_sample) ** 2
    sum_of_squares = np.sum(squared_diff, axis=1)

    # 预测数字
    predicted_digit = np.argmin(sum_of_squares)

    # 与真实标签进行比对
    if predicted_digit == val_labels[i]:
        correct_predictions += 1

# 计算准确率
accuracy = (correct_predictions / len(val_pixels)) * 100
print(
    f"验证集测试完成！准确率为: {accuracy:.2f}% ({correct_predictions}/{len(val_pixels)})"
)
```
&emsp;&emsp;模板法经过测试，前 2000 行验证的准确率为 81.65% ，说明有效，但还有很大优化空间。

&emsp;&emsp;那么具体该怎么优化呢？

## 加权法

> 小步快跑，试错迭代。  &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;——马化腾

&emsp;&emsp;不难看到模板法的局限性。这种方法将所有 784 个像素都给予了相同的权重。而实际上，对于一张手写数字图片，未必所有像素都得一样重要。例如，对于数字 0 而言，假如图片中间出现了一块很亮的像素，则几乎可以直接排除了。

&emsp;&emsp;所以，我们可以对每一类数字，整理其 784 个坐标的权重。如果某个像素与这个数字具有一定的正相关性，那就给予一个正权重，反之则为负权重。如此，对于单张图片，我们可以给出一个 10x784 的权重矩阵 W ，再左乘代表灰度的 784x1 的矩阵 X ，得到一个加权和构成的行向量 Z。

![](/assets/img/Z.svg)

&emsp;&emsp;那么这里的权重 W 该如何确定呢？总不能手工一个个标记吧。有没有一种算法，能够帮我们确定这个合适的权重呢？

&emsp;&emsp;答案是肯定的。但必须指出，这里的算法可能并不一定像计算平均模板那样，简洁直观，一步到位地 **确定** 合适的权重，而往往是以一种可重复执行的步骤，去 **逼近** 这个合适的权重。毕竟我们有几万条数据，为这样可重复执行的步骤创造了条件。而迭代优化，也是机器学习的核心思想之一。

&emsp;&emsp;现在，我们的行动方案已然确定——找到一种可重复执行的步骤，通过这几万条数据，让机器去 **预测** 每类数字所对应的坐标权重。它的起点可以很粗糙，但应当能够根据预测的成功与否，倒逼机器动态调整参数，最后收敛到一个稳定的值附近。

&emsp;&emsp;那么进一步拆解目标，就变成了

&emsp;&emsp;**1.找到一种方法来刻画机器预测的结果是 “好” 还是 “不好” ，并反馈给机器。**

&emsp;&emsp;**2.让机器去分锅，找到出问题的参数，并调整。**

&emsp;&emsp;如此，不断往复，直到训练完这 4 万多个数据集。可以设想，经过大量的训练，机器对每个参数的预测将会越来越准确。

### 激活函数与损失函数

&emsp;&emsp;想要刻画机器预测的结果，首先要统一机器预测的结果。单纯的矩阵乘积拿出来效果并不佳，因为结果的上下限与符号不确定，难以系统比较。

&emsp;&emsp;我们想起了概率论，让机器输出一个项数为 10，和为 1的概率数组，如\[0.1,0.2,...,0.2,0.3\]，描述对于这张图片，分别是数字 0/1/2...9 的把握是多少。

&emsp;&emsp;那么，我们如何将无界的加权和，映射到有界的概率呢？由此我们引入了`激活函数Softmax`，它有着一系列良好的性质，能将无界的输出值 Z 映射到 0-1 的概率分布，且保留原来的单调性。最关键的是，Softmax 的导数非常好求，意味着我们可以方便地对它进行其他处理。

### 反向传播与梯度下降

&emsp;&emsp;显然，机器如果想要降低错误，就必须要将损失函数降到最低。要想降低损失函数，就必须改变权重矩阵 W 。而这里有一个传播过程，从 L 通过损失函数传到概率 P ，再通过激活函数传到加权和 Z ，最后到达权重矩阵 W ，这个过程就是`反向传播`
![反向传播示意图](/assets/img/bp.svg)

&emsp;&emsp;在整个过程中，我们关心的是，对于权重矩阵的某个改变量 ∂W ，整个 L 最后的改变量 ∂L。你一定会感到特别熟悉，因为这就是大家都学习过的偏导数。根据链式法则，容易求出 L 关于 W 的偏导数:

![](/assets/img/bp2.svg)

&emsp;&emsp;得到了这个公式，我们就可以理解损失函数 L 与 权重矩阵 W 的关系了。由于灰度矩阵 X 非负，要想让损失函数越小（模型越正确），W 必须沿着`梯度下降`的方向更新:
![这就是大名鼎鼎的“梯度下降”](/assets/img/gc.svg)

&emsp;&emsp;在梯度前我们引入了一个系数 η ，此为学习率，描述参数沿梯度方向移动的距离，用于控制参数更新的步长。如果学习率太低，步子迈得太小，整个模型会收敛得很慢，训练时间长，也可能陷入局部最优。但如果学习率过高，参数可能会来回振荡，甚至发散。因而精确控制学习率尤为关键。

&emsp;&emsp;让我们来理解一下这个公式。假如某张图片的标签是 2 ，且模型对于该图片为 2 的预测概率为 P2 。这说明模型预测正确，P2应该越大越好，那么就有
![对正确类别的预测，权重增大](/assets/img/gc2.svg)

&emsp;&emsp;由于概率不大于 1 ，整个梯度小于等于 0 ，参数会向增大的方向移动，也就是提高该像素位置的权重，模型就会更“自信”地提高该位置像素与标签 2 的正相关性。

&emsp;&emsp;还是这张图片，正确答案为 2，模型对于该图片为 3 的预测概率为 P3 。显然这个预测不大对，P3不应该太大，那么就有 
![对错误类别的预测，权重减小](/assets/img/gc3.svg)

&emsp;&emsp;由于概率不小于 0 ，整个梯度大于等于 0 ，参数会向减小的方向移动，也就是降低该像素位置的权重，模型会降低该位置像素与标签 3 的正相关性，确实有效地符合了我们对这个问题的要求。

&emsp;&emsp;现在，我们已经跑通了整个流程：计算加权→激活函数→预测概率→损失函数→反向传播→梯度下降→权重更新，使用 Numpy 库与 Pandas 库即可完成，具体实现代码如下：

```Python
import numpy as np

def softmax(Z):
    # 激活函数
    # 减去最大值是为了防止指数运算溢出（NumPy 的数值稳定性技巧）
    exp_Z = np.exp(Z - np.max(Z, axis=1, keepdims=True))
    return exp_Z / np.sum(exp_Z, axis=1, keepdims=True)


def compute_loss(probs, y_true):
    # 损失函数：交叉熵损失
    batch_size = probs.shape[0]
    # 提取出正确类别的预测概率，计算交叉熵损失
    correct_log_probs = -np.log(probs[range(batch_size), y_true] + 1e-15)
    return np.sum(correct_log_probs) / batch_size

import pandas as pd

# 1. 读取并划分数据

print("正在读取原始训练数据...")
raw_data = pd.read_csv("train.csv")

val_data = raw_data.iloc[:2000]
train_data = raw_data.iloc[2000:]

# 提取特征并归一化像素值 0~1 
train_labels = train_data.iloc[:, 0].values
train_pixels = train_data.iloc[:, 1:].values / 255.0

val_labels = val_data.iloc[:, 0].values
val_pixels = val_data.iloc[:, 1:].values / 255.0

print(f"数据准备完毕。训练集: {train_pixels.shape}, 验证集: {val_pixels.shape}")


# 2. 初始化权重

# W 的形状是 (784, 10)，代表 784 个像素坐标对应 10 个数字的权重
W = np.random.randn(784, 10) * 0.01
# b 的形状是 (1, 10)，代表 10 个数字的基础分（偏置）
b = np.zeros((1, 10))

# 超参数设置
learning_rate = 0.1  # 学习率
batch_size = 64  # 批大小：每次抓取 64 张图
epochs = 5  # 重复训练 5 遍

# 3. 开始训练

num_samples = train_pixels.shape[0]

for epoch in range(epochs):
    print(f"\n--- 开始第 {epoch + 1} 轮训练 ---")

    # 打乱训练数据
    permutation = np.random.permutation(num_samples)
    X_shuffled = train_pixels[permutation]
    y_shuffled = train_labels[permutation]

    # 按批次（Batch）进行训练
    for i in range(0, num_samples, batch_size):
        X_batch = X_shuffled[i : i + batch_size]
        y_batch = y_shuffled[i : i + batch_size]
        current_batch_size = X_batch.shape[0]

        # ---- 步骤 A: 前向传播 
        
        # 矩阵点积：(64, 784) 乘 (784, 10) -> (64, 10) 的得分矩阵
        Z = np.dot(X_batch, W) + b
        # 调用激活函数计算概率
        probs = softmax(Z)

        # ---- 步骤 B: 反向传播
        # 处理真实标签
        y_one_hot = np.zeros_like(probs)
        y_one_hot[range(current_batch_size), y_batch] = 1.0

        # 梯度
        dZ = probs - y_one_hot

        # 分摊权重
        # (784, 64) 点积 (64, 10) -> (784, 10) 的权重更新方向
        dW = np.dot(X_batch.T, dZ) / current_batch_size
        db = np.sum(dZ, axis=0, keepdims=True) / current_batch_size

        # ---- 步骤 C: 梯度下降
        W = W - learning_rate * dW
        b = b - learning_rate * db

    
    # 4. 每一轮结束，在验证集上检验成果
  
    val_Z = np.dot(val_pixels, W) + b
    val_probs = softmax(val_Z)
    val_predictions = np.argmax(val_probs, axis=1)

    # 计算准确率
    accuracy = np.mean(val_predictions == val_labels) * 100
    loss = compute_loss(val_probs, val_labels)
    print(f"第 {epoch + 1} 轮完成 -> 验证集损失: {loss:.4f} | 准确率: {accuracy:.2f}%")
```

&emsp;&emsp;在学习率为 0.1 ，重复训练次数为 5 的条件下，最终的训练准确率稳定在 92% 附近，相比模板法提升了 10% ，是非常可观的进步。

## 神经网络

### 多层感知机

> Even when it works, dig into why. &emsp;&emsp;即便可行，亦探真理。

&emsp;&emsp;我们通过权重矩阵 W 与灰度矩阵 X 的乘积描述了一个数字的“可能性”。这种算法固然不错，但总感觉不太符合我们判断数字的 ***直觉*** 。数字总感觉不太应该拆成一个个像素小点，而更应该看作是一系列笔画特征的组合。例如 1 是一竖， 7 是一个短横线加上一根长斜线，8 是两个小圆圈上下叠放......
![](/assets/img/digit.png)

&emsp;&emsp;我们不禁会想，那如果我们做两遍加权和，第一遍对各个像素的灰度做加权，用来描述横、圈、竖线这种笔画特征，第二遍用这些笔画特征做加权，描述这 10 种不同的数字，会不会更加精细，更为准确呢？

&emsp;&emsp;这个想法非常巧妙，它非常贴近人脑的生理构造！人脑有近千亿神经元，每个神经元间通过树突/轴突链接，构建起一个巨大规模的神经网络。各个神经元相当于不同的小分类器，接受不同领域的信号，并通过神经网络向其它神经元传递。整个传播的过程是有条件的：需要输入信号（加权和）达到一定的阈值后才会触发传播。从宏观上来看，神经网络将复杂的目标层层拆解，最终通过大量基础元素的组合来实现对世界的认知。

&emsp;&emsp;在机器学习领域，这种类似人脑神经元的结构被称为`感知机`。感知机是一个线性分类器，能够根据输入矩阵 X 与权重矩阵 W，通过加权和判断是否超过阈值，从而输出 0 或 1 。刚刚使用过的“加权法”就是一个典型的感知机，它在一个 784 维的空间中，用 10 条笔直的线（10 类数字的加权和）对 10 类数字进行划分。

&emsp;&emsp;可想而知这种线性分类的局限——不同类型数字的分界线未必都是分明的，更是难以被简单粗暴地用一条线切分的。如果我们构造一种稍微复杂的函数，能够不那么笔直，在边界处“弯曲”一些，想来肯定会更加精准。

&emsp;&emsp;这需要引入非线性。考虑最简单的情况：让第一层感知机通过某种非线性的方式激活后，指向圆圈，短横，斜线这种笔画样式；第二层感知机和之前的方法类似，接收第一层的输出，再通过加权和反映各种笔画样式的组合，通过Softmax激活成 0 1 2 3 这些数字的概率。理论上，我们可以通过无限堆叠这种“非线性”层来逼近任何函数！`多层感知机``（Multi Layer Perception, MLP）`概念也就应运而生了。

&emsp;&emsp;所以现在困扰我们的头号难题变成了：这个非线性的激活函数，到底怎么选取？

&emsp;&emsp;既然输入层通过这个函数激活后，会指向各种笔画样式，那这个函数需要做这样一件事：只聚焦对建立样式有关的信号，抹除无关的信号。

&emsp;&emsp;这个函数就是著名的 ReLU 激活函数，非常简洁：

![](/assets/img/ReLU.svg)

&emsp;&emsp;从宏观上来看，这个激活函数只关心那些对于某笔画样式具有正相关的像素。对于那些无相关或者不相关的部分一概忽略。同时 ReLU 的性质十分良好，对于正相关的部分会原封不动地保留，无论迭代多少层，都不会扩大或者缩小；它在小于等于 0 时的导数为 0 （0 处虽然不可导但也可看作为 0），这意味着在反向传播的“分锅”过程中，那些零贡献的灰度值所构成的梯度也会被自然忽略，大大节省了运算开销。

&emsp;&emsp;然而，多层感知机也存在不可避免的问题，就是`算法黑箱`。在实际训练过程中，我们再也无法像单层感知机那样，明确得知模型对每一个像素坐标灰度的加权情况。换而言之，我们无法直接看到中间层到底感知到了哪些“笔画特征”，即便单独提取了这些特征，也很难人为干预，因为中间层与其它层耦合在一起，牵一发而动全身。因此，这些不直接连接原始输入层与输出层的部分，也被称为`隐藏层`。

![如果说第一层还能看得出特征，那最后一层是什么也看不出来](/assets/img/blackbox_MLP.png)

&emsp;&emsp;既然无从干预过程，我们就只能关注结果。然而结果正义往往并不等于程序正义。随着模型越来越复杂，依赖于严格逻辑的数学推导会变得越来越无力，我们很难确知在输出背后的那个黑箱里，究竟藏着怎样的谜题。

&emsp;&emsp;现在，我们引入了新的非线性激活函数ReLU，构造一个多隐藏层感知机，来提取高维特征。其余损失函数与验证部分可参考之前，完整代码如下：
```Python
# 基于Python 3.13.9和PyTorch 2.7.1的双隐藏层感知机
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, Dataset
import pandas as pd
import numpy as np

# 1. 设定超参数

BATCH_SIZE = 64          # 每个批次处理 64 张图片
EPOCHS = 10              # 重复使用训练集10遍
LEARNING_RATE = 0.1     # 学习率
DEVICE = torch.device("cuda" if torch.cuda.is_available() else "cpu") #利用GPU加速


# 2. 载入数据集

class LocalMNISTDataset(Dataset):
    """用于读取本地 CSV 格式 MNIST 数据集的自定义类，也可使用dataset官方MNIST数据集"""
    def __init__(self, pixels, labels):
        # 将像素数据归一化到 0~1，并转换为 PyTorch 张量
        self.pixels = torch.tensor(pixels / 255.0, dtype=torch.float32)
        self.labels = torch.tensor(labels, dtype=torch.long)
        
    def __len__(self):
        return len(self.labels)
        
    def __getitem__(self, idx):

        return self.pixels[idx], self.labels[idx]

raw_data = pd.read_csv("train.csv")

# 切分训练集与验证集
val_df = raw_data.iloc[:2000]
train_df = raw_data.iloc[2000:]

# 提取特征并分离标签
train_labels = train_df.iloc[:, 0].values
train_pixels = train_df.iloc[:, 1:].values

val_labels = val_df.iloc[:, 0].values
val_pixels = val_df.iloc[:, 1:].values

# 构建 PyTorch 专属的数据集实体
train_dataset = LocalMNISTDataset(train_pixels, train_labels)
test_dataset = LocalMNISTDataset(val_pixels, val_labels)

train_loader = DataLoader(dataset=train_dataset, batch_size=BATCH_SIZE, shuffle=True)
test_loader = DataLoader(dataset=test_dataset, batch_size=BATCH_SIZE, shuffle=False)

print(f"本地数据准备完毕。训练集: {train_pixels.shape[0]} 条，验证集: {val_pixels.shape[0]} 条。")


# 3. 双隐藏层神经网络

class SimpleMLP(nn.Module):
    def __init__(self):
        super(SimpleMLP, self).__init__()
        
        self.fc1 = nn.Linear(784, 512)  # 第一层：把 784 个原始像素映射到 512 个基础特征
        self.relu1 = nn.ReLU()          # 激活函数ReLU
        
        self.fc2 = nn.Linear(512, 256)  # 第二层：把 512 个基础特征组合成 256 个更高阶的特征
        self.relu2 = nn.ReLU()          # 激活函数ReLU
        
        self.fc3 = nn.Linear(256, 10)   # 第三层：最终决策，结算出 10 个数字各自的得分
        
    def forward(self, x):
        
        # 1. 经历第一次加权和截断
        x = self.fc1(x)
        x = self.relu1(x)
        
        # 2. 经历第二次加权和截断
        x = self.fc2(x)
        x = self.relu2(x)
        
        # 3. 最终输出原始得分（PyTorch 自动接续 Softmax）
        return self.fc3(x)

# 实例化模型
model = SimpleMLP().to(DEVICE)

# 4. 损失函数与梯度下降
criterion = nn.CrossEntropyLoss()  # 交叉熵损失函数
optimizer = optim.SGD(model.parameters(), lr=LEARNING_RATE)  # 优化器：随机梯度下降

# 5. 训练与验证循环

if __name__ == '__main__':
    print(f"当前运行设备: {DEVICE}")
    print("开始训练多层感知机（MLP）...\n")
    
    for epoch in range(EPOCHS):
        # --- 训练阶段 ---
        model.train()
        running_loss = 0.0
        for data, target in train_loader:
            data, target = data.to(DEVICE), target.to(DEVICE)
            
            optimizer.zero_grad()             # 1. 抹除残余梯度
            outputs = model(data)             # 2. 计算得分
            loss = criterion(outputs, target) # 3. 交叉熵损失
            loss.backward()                   # 4. 反向传播
            optimizer.step()                  # 5. 梯度下降
            
            running_loss += loss.item()
            
        avg_train_loss = running_loss / len(train_loader)
        print(f"Epoch [{epoch+1}/{EPOCHS}] - 训练集损失率: {avg_train_loss:.4f}")
        
        # --- 验证阶段 ---
        model.eval()
        val_loss = 0.0  # 用来累加验证集总损失的记账本
        correct = 0
        
        with torch.no_grad(): 
            for data, target in test_loader:
                data, target = data.to(DEVICE), target.to(DEVICE)
                outputs = model(data)
                
                # 验证集损失
                loss = criterion(outputs, target)
                val_loss += loss.item()
                
                # 输出预测结果
                pred = outputs.argmax(dim=1, keepdim=True)
                correct += pred.eq(target.view_as(pred)).sum().item()
                
        avg_val_loss = val_loss / len(test_loader)  # 计算验证集平均损失率
        accuracy = 100. * correct / len(test_loader.dataset)
        
        print(f"- 验证集损失率: {avg_val_loss:.4f} | 准确率: {accuracy:.2f}%\n")
```

&emsp;&emsp;在学习率为 0.1 ，学习轮次为 10 的条件下，准确率可以稳定在 97.5% 以上，且损失率均处于 0.1 以下，是非常不错的结果。

### 卷积神经网络 ###

&emsp;&emsp;我们利用多隐藏层感知机，在 MNIST 手写数字识别这个项目上达到了 97% 的准确率。但别忘了， MNIST 只是一个 28 × 28 的灰度图像。如果图片的分辨率高一些，变成 400 × 400 甚至更大，或者图片的色彩空间变成 RGB 的彩色图像，MLP 的局限性就会显现。

&emsp;&emsp; MLP 最大的障碍，在于 **参数爆炸** 。在 MNIST 中，每个特征的分类器负责接收输入层的 784 个参数值 ，决定它们的权重。因此每个全连接层的连接数量是 784 × 特征数量，尚且能够接受。但如果变成了 400 × 400 的三通道 RGB 图像，就会有 400 × 400 × 3 = 480000 个参数值。相应的连接数量会变成 48 万 × 特征数量，机器肯定处理不过来。

&emsp;&emsp;这意味着，如果我们需要找一个能够处理更多参数值的神经网络，就必须得放弃传统的像素线性组合，寻找另一种能提取图像特征，同时又不引入过多参数的方法。

&emsp;&emsp;于是我们设计了`卷积神经网络``(Convolutional Neural Network, CNN)`。将图像值看作是一个由像素组成的二维平面，卷积核是一个小的矩阵，自带参数（权重），反映某个特征，在滑动的过程中不断与图片像素值计算加权和（Hadamard 积）。

![](/assets/img/conv.gif)

&emsp;&emsp;卷积神经网络之所以高效的本质，在于其 **聚焦** 以及 **可复用** 性 。

&emsp;&emsp;我们知道，图像中的特征，往往只由集中在局部的一些像素决定。相比传统 MLP 全连接层需要关注整个图像的所有像素，卷积核通过聚焦在一个 3 × 3 的小窗口，舍去了距离更远，也更不相关的像素，做到了抓大放小，集中且高效。

&emsp;&emsp;同时，在复杂图像中，某个特征可能会多次出现。卷积核会滑动遍历图片的所有部分，因此无论这些特征处于哪些位置，都能得到相同的加权和。而传统 MLP 中，分类器的权重是与像素位置一一对应的，一旦引入新的特征，就必须要引入一组新的权重，计算出的加权和也可能不一样。

&emsp;&emsp;在卷积完成后，图像就会变成一张新的特征图——像素值变成了卷积后的加权和。此时的参数量仍然是比较大的，我们该怎样继续降维呢？

&emsp;&emsp;不妨借鉴一下模版法。模版法通过一张“平均图”代表所有图片的特征，提取主要信息的同时也丢掉了无必要的噪音。而在卷积神经网络中，类似的降维操作被称为`池化(pooling)`。池化有多种规则，模板法的取平均就是平均池化，此外还有最大池化，随机池化与 L2 范数池化等。

![](/assets/img/pool.gif)

&emsp;&emsp;将图像经过卷积与池化后，数据量就会下降很多，再将其展开成一维量，就可以进入到传统 MLP 的流程了。下面仍然以 MNIST 为例，给出卷积神经网络的代码：
```python
import os
import time
import numpy as np
import pandas as pd
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset
import matplotlib
import matplotlib.pyplot as plt

# ==================== 全局配置 ====================
# 解决OpenMP运行时可能的冲突问题
os.environ.setdefault("KMP_DUPLICATE_LIB_OK", "TRUE")
# 选择设备
DEVICE = torch.device("cuda" if torch.cuda.is_available() else "cpu")
# 设置种子
SEED = 42  
torch.manual_seed(SEED)
np.random.seed(SEED)


# ==================== 1. 数据加载与预处理 ====================
def load_data(csv_path="train.csv", train_ratio=0.9):
    
    # 读取CSV文件（第一列是标签，后面784列是28x28像素值）
    raw = pd.read_csv(csv_path)
    
    # 提取标签
    labels = raw.iloc[:, 0].values.astype(np.int64)
    
    # 提取像素值并归一化
    pixels = raw.iloc[:, 1:].values.astype(np.float32) / 255.0
    
    # 重塑为CNN输入格式：(样本数, 通道数=1, 高度=28, 宽度=28)
    pixels = pixels.reshape(-1, 1, 28, 28)
    
    # 随机打乱并划分训练集和验证集
    n = len(labels)
    idx = np.random.RandomState(SEED).permutation(n)
    cut = int(n * train_ratio)  # 训练集切分点
    tr_idx, va_idx = idx[:cut], idx[cut:]  # 90%训练，10%验证
    
    return (pixels[tr_idx], labels[tr_idx]), (pixels[va_idx], labels[va_idx])


def make_loader(X, y, batch_size, shuffle):
    
    # 将numpy数组转换为PyTorch张量
    Xt = torch.tensor(X, dtype=torch.float32)   # 图像数据用float32
    yt = torch.tensor(y, dtype=torch.long)      # 标签用long（分类问题）
    
    # 封装为TensorDataset
    ds = TensorDataset(Xt, yt)
    
    # 创建DataLoader，支持批量迭代
    return DataLoader(ds, batch_size=batch_size, shuffle=shuffle, num_workers=0)


# ==================== 2. CNN模型定义 ====================
class SimpleCNN(nn.Module):
    
    def __init__(self):
        super().__init__()
        
        # ---------- 特征提取部分（卷积+池化）----------
        self.features = nn.Sequential(
            # 第1层卷积：输入1通道（灰度图），输出16通道，3x3卷积核
            # 输入: 28x28x1 → 输出: 26x26x16
            nn.Conv2d(1, 16, kernel_size=3, padding=0),
            nn.ReLU(inplace=True),  # 激活函数，引入非线性
            
            # 第1层池化：2x2最大池化，步长=2
            # 输入: 26x26x16 → 输出: 13x13x16（尺寸减半）
            nn.MaxPool2d(2),
            
            # 第2层卷积：输入16通道，输出32通道，3x3卷积核
            # 输入: 13x13x16 → 输出: 11x11x32（13-3+1=11）
            nn.Conv2d(16, 32, kernel_size=3, padding=0),
            nn.ReLU(inplace=True),
            
            # 第2层池化：2x2最大池化
            # 输入: 11x11x32 → 输出: 5x5x32（11//2=5，向下取整）
            nn.MaxPool2d(2),
        )
        
        # ---------- 分类器部分（全连接层）----------
        self.classifier = nn.Sequential(
            nn.Flatten(),  # 将三维特征图展平为一维向量：32*5*5 = 800
            nn.Linear(32 * 5 * 5, 128),  # 全连接层：800 → 128
            nn.ReLU(inplace=True),       # 激活函数ReLU
            nn.Linear(128, 10),          # 输出层：128 → 10（对应10个数字类别）
        )
    
    def forward(self, x):
        # 先经过特征提取（卷积+池化），再经过分类器（全连接）
        return self.classifier(self.features(x))


# ==================== 3. 训练主函数 ====================
def train(epochs=5, batch_size=64, lr=1e-3):
    print(f"Device: {DEVICE}")
    
    # ----- 步骤1：加载数据 -----
    (Xtr, ytr), (Xva, yva) = load_data()
    print(f"Train: {Xtr.shape}, Val: {Xva.shape}")
    
    # 创建训练和验证数据加载器
    train_loader = make_loader(Xtr, ytr, batch_size, shuffle=True)
    val_loader   = make_loader(Xva, yva, batch_size, shuffle=False)
    
    # ----- 步骤2：初始化模型、优化器、损失函数 -----
    model = SimpleCNN().to(DEVICE)  # 将模型移动到设备
    optimizer = optim.Adam(model.parameters(), lr=lr)  # Adam优化器
    criterion = nn.CrossEntropyLoss()  # 交叉熵损失函数
    
    # ----- 步骤3：训练循环 -----
    history = {"train_loss": [], "val_loss": [], "val_acc": []}  # 记录训练历史
    best_acc, best_state = 0.0, None  # 最佳验证准确率及对应模型参数
    t0 = time.time()  # 记录开始时间
    
    for epoch in range(1, epochs + 1):
        # ---------- 训练阶段 ----------
        model.train()  # 设置为训练模式（启用dropout/batch norm等）
        tr_loss, n_seen = 0.0, 0
        
        for xb, yb in train_loader:
            # 将数据移动到设备（GPU/CPU）
            xb, yb = xb.to(DEVICE), yb.to(DEVICE)
            
            # 1. 梯度重置
            optimizer.zero_grad()
            
            # 2. 前向传播
            out = model(xb)
            
            # 3. 计算损失
            loss = criterion(out, yb)
            
            # 4. 反向传播：计算梯度
            loss.backward()
            
            # 5. 梯度下降（Adam）
            optimizer.step()
            
            # 累计损失（用于计算平均损失）
            tr_loss += loss.item() * xb.size(0)
            n_seen += xb.size(0)
        
        # 计算平均训练损失
        tr_loss /= n_seen
        
        # ---------- 验证阶段 ----------
        model.eval()  # 设置为评估模式（不更新参数，不使用dropout）
        va_loss, correct, n_va = 0.0, 0, 0
        
        # 禁用梯度计算（节省内存和计算）
        with torch.no_grad():
            for xb, yb in val_loader:
                xb, yb = xb.to(DEVICE), yb.to(DEVICE)
                
                # 前向传播
                out = model(xb)
                
                # 计算验证损失
                va_loss += criterion(out, yb).item() * xb.size(0)
                
                # 计算准确率：获取预测类别（argmax取最大概率对应的索引）
                correct += (out.argmax(1) == yb).sum().item()
                n_va += xb.size(0)
        
        # 计算平均验证损失和准确率
        va_loss /= n_va
        acc = correct / n_va
        
        # 记录历史
        history["train_loss"].append(tr_loss)
        history["val_loss"].append(va_loss)
        history["val_acc"].append(acc)
        
        # ----- 保存最佳模型 -----
        marker = ""
        if acc > best_acc:
            best_acc = acc
            # 深拷贝当前模型参数（移动到CPU存储）
            best_state = {k: v.detach().cpu().clone() for k, v in model.state_dict().items()}
            marker = "  ← best"
        
        # 打印训练进度
        print(f"Epoch {epoch}/{epochs}  "
              f"train_loss={tr_loss:.4f}  val_loss={va_loss:.4f}  "
              f"val_acc={acc*100:.2f}%{marker}", flush=True)
    
    # ----- 步骤4：保存结果 -----
    elapsed = time.time() - t0
    print(f"\nDone. best_val_acc={best_acc*100:.2f}%  ({elapsed:.1f}s)")
    
    # 保存训练历史（损失、准确率曲线数据）
    np.savez("cnn_history.npz",
             train_loss=np.array(history["train_loss"]),
             val_loss=np.array(history["val_loss"]),
             val_acc=np.array(history["val_acc"]),
             best_acc=best_acc)
    
    # 保存最佳模型参数（用于后续推理或继续训练）
    if best_state is not None:
        torch.save(best_state, "best_simple_cnn.pth")
        print("Saved best_simple_cnn.pth and cnn_history.npz")


# ==================== 超参数设置 ====================
if __name__ == "__main__":
    # 启动训练（5个epoch，批次大小64，学习率0.001）
    train(epochs=5, batch_size=64, lr=1e-3)
```

&emsp;&emsp;最终训练结果如下，在学习轮次为 5 ，学习率为 0.001 的条件下，准确率来到了 98.52%. 大获全胜的结果！

# 总结 #
&emsp;&emsp;从最初 82% 准确率的模板法，到 92% 的单层感知机（加权法），再到 97% 的双隐藏层感知机，98% 的卷积神经网络，后者总是继承着前者的影子，却又脱胎于前者的局限。模板法是显式的硬匹配，单层感知机将其软化为可学习更新的权重，双隐藏层在此基础上生长出特征组合的能力。

&emsp;&emsp;这是一条“增维”的路径，通过更复杂的模型、更长的代码、更大的运算开销来达到更准确的结果，很标准，很努力，但不够美。

&emsp;&emsp;而卷积神经网络石破天惊。它反其道而行之，选择做“减法”，将全连接网络的全局视野收敛为局部感知的核，却又保留其深层堆叠的精髓。因而在降低参数量的同时，还得到了更为准确的结果。
