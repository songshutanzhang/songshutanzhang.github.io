# 真心话大转盘题单

题库版本 1.1.109 · 136 道在用题

## 自我认知与个人成长

- Q001 和几年前相比，你觉得自己最大的变化是什么？不能只讲变成熟了。
- Q002 有没有一句话，一件事或者一个人，你以前深信不疑，后来却改了看法？
- Q003 有哪些别人看来你的优点，自己反而经常感到困扰？（相信你不是凡尔赛）
- Q004 你最不希望自己将来变成什么样的人？
- Q005 你觉得自己是一个更在意过程，还是更在意结果的人？
- Q006 有没有一种别人对你的评价，你表面上不在意，实际上很在意？
- Q007 什么时候你觉得自己在主导人生，什么时候又觉得自己在被环境推着走？
- Q008 如果能回到自己曾经很迷茫，很无助的某个时刻，你想对那时候的自己说些什么？
- Q009 你有没有某个时刻，突然意识到自己已经长大了？
- Q010 你觉得家里给你留下了哪些特质？有没有哪一点，是你对家里的期待说「不」以后慢慢形成的？
- Q011 你觉得你自己，会更容易先做了再说，还是三思而后行？或者经常三思，但很少行？
- Q012 你最近有没有一个正想改掉的坏习惯？
- Q013 你觉得自己是个很在意体面的人吗？
- Q014 你觉得自己是一个容易被理解的人吗？你希望别人理解你到什么程度？
- Q024 你小时候听过的话里，有没有哪句到现在还记得？
- Q051 你有没有对一个人产生过非常矛盾的感情？
- Q052 觉得日子有点困顿的时候，你通常会去做什么？
- Q054 你有没有主动放弃过自己其实很舍不得的人或者事物？现在回想，你还会做出同样的选择吗？
- Q067 有哪些别人一直以来对你的印象，你其实并不太认同？
- Q070 最近工作、生活、感情上有没有一些烦心事，能不能跟大家说说？
- Q084 你是否相信一个人身上存在一些特质，无论经历了什么，都永远不会改变？
- Q092 你的 MBTI 是什么？知道的话，可以让大家先猜猜看。
- Q095 回想起一段已经结束的关系，你觉得从结束至今的这段时间带给你的，更多是理解与放下，还是感慨与介怀？
- Q097 分享一个你的圈名 / 昵称 / 个性签名的来历。
- Q103 有没有一件事，直到你真正经历过，才发现它和自己原先想象得很不一样？

## 友情与社会关系

- Q017 有没有哪个人，你当时无法理解 TA 的所作所为，但是经过一段时间后，你又有点理解当时的 TA 了？
- Q023 你觉得相比过去，你现在更容易，还是更难向别人付出真心了？你是如何看待自己的这种变化呢？

- Q031 有没有哪个「陌生人」，本来和你不会有交集，最后却成了朋友？

- Q035 如果朋友得到了你期盼很久的机会，而你没得到，你会怎么办？如果你们本来就是竞争对手，你的做法会变吗？

- Q038 有没有一段友情，让你感觉，即使很久不联系，也不会真正冷却？
- Q039 有些事说出来可能会伤感情，瞒着又可能有一天被对方知道。碰上这种事，你会开口吗？
- Q040 两个好朋友闹了矛盾，你什么时候会帮忙传话，什么时候会让他们自己谈？
- Q041 你觉得自己在人际关系中，从结果上来看，是付出的部分更多，还是接受的部分更多？
- Q042 你有没有遇到过一个人，让你对自己产生了不一样的认识？
- Q043 如果一个朋友后来成了你的上级或下属，你觉得这段友情会怎么变？
- Q044 如果一段友情只有一方主动约见或联系，你还会愿意继续维系下去吗？什么情况下会呢？
- Q057 在一段你想维持的关系里，有没有哪个难关是你们一起挺过来的？当时是什么帮了你们？
- Q059 哪些关系淡了，你能接受？哪些关系你还愿意再努力一下？
- Q071 有没有为了别人写过小作文？
- Q074 你有没有跟别人产生过比较大的误会，最后是怎么处理的？
- Q090 有没有和谁闹掰 / 分手之后又和好 / 复合 的经历？你觉得相比闹掰前，你们间的心结变得更多了还是更少了？
- Q099 有没有一个你一直想感谢、却还没来得及好好道谢的人？你想对 TA 说什么？
- Q120 你有没有「被坑过」的经历？

- Q173 有没有对某个人「滤镜碎了」的经历？

## 爱情与亲密关系

- Q022 你觉得你算是「焦虑型依恋」，还是「回避型依恋」，还是两者都有？

- Q047 对你来说，恋爱会在生活里占多大的位置？
- Q048 如果一个人同时对两个人心动，你觉得该怎么办？你觉得道德底线应该在哪里？
- Q049 恋爱中，哪些事你希望对方主动告诉你？哪些事你觉得双方可以各自保留？
- Q050 喜欢上一个人时，哪些信号会让你觉得可以开口？
- Q053 两个人在一起，共同兴趣对你来说有多重要？
- Q055 如果你很喜欢一个人，但之后发现，你们的未来规划完全不同，什么会让你愿意妥协，什么会让你决定放手？
- Q056 你觉得一个人一定要经历一些挫折，才能在感情中变得成熟吗？
- Q058 你很看重恋爱过程中的仪式感吗？
- Q060 讲讲你最「纯爱」或最「恋爱脑」的一次经历。
- Q088 如果一段关系能给你爱情，却无法满足你的性需求；或者能满足你的性需求，却没有爱情，你能接受其中任何一种吗？

- Q093 在感情上，你觉得自己是一个需要时间慢慢产生好感的人，还是容易在初识阶段就对一个人产生心动的人？
- Q102 讲讲你觉得自己最舔的一次经历，如果有的话。
- Q104 在你交往过的关系里，有没有什么事让你不安，但你也想过「只要别让我看到就行」？当时为什么这样想？
- Q105 在你交往过的一段关系里，有哪些事情让你觉得对方值得信任？
- Q106 你觉得「海王 / 海后」和「渣」是一回事吗？一个人同时与多人保持暧昧，是否就构成道德或者品行问题？你认为还有什么因素值得考虑？
- Q107 失恋过嘛，最难受的那段时间，是如何平复自己的心情的？
- Q108 回头看一段结束的恋爱，有什么你现在会用不同的方式处理？会因此觉得遗憾，或者后悔吗？
- Q109 分手 / 绝交时，哪些事情有必要在告别前说清楚？
- Q110 你接受异地恋吗？如果可以，你大概能接受多远，多久联系一次？
- Q111 你如何看待「situationship」（即那些有着恋人般的亲密，却始终没有明确关系定义的两个人）你觉得这种关系是一种自由，还是只吃爱情的甜，不吃爱情的苦？
- Q112 如果TA是一位肢体残障者，你会勇敢地说出爱吗？
- Q113 你觉得结婚前，有必要先同居一段时间，试着磨合生活习惯吗？
- Q114 一个人应该如何处理他人的单方面好感？不误导、不做虚假的承诺即可，还是需要及时澄清，即使可能破坏现有的相处模式？
- Q115 在亲密关系里，想公开合照的一方和想保留隐私的一方，可以怎样商量？
- Q116 有没有一个时刻，让你发现自己对 TA 已经不只是普通好感了？
- Q118 如果两个人已经拥有恋人般的亲密、理解、信任与承诺，甚至也建立起了责任和安全感，却始终没有正式确立恋人关系，你认为他们之间可能还缺少什么？还是说，这本身未必是一个问题？
